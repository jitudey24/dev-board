# DevBoard

A task-board interface practice project built with HTML and utility-first CSS. The page uses a dashboard layout with DevBoard branding and a clean workspace.

## Features
- DevBoard dashboard header
- Task-board style page layout
- Poppins typography
- DaisyUI and Tailwind CSS styling

## Technologies
- HTML5
- Tailwind CSS
- DaisyUI
- Google Fonts

## Run Locally
1. Clone this repository.
2. Open `index.html` in a modern browser.
3. Keep the `assets` folder in its original location.

## Project Purpose
A Programming Hero practice project focused on dashboard layout, utility classes, and interface composition.
